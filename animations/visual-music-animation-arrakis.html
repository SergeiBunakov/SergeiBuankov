Description

This project was the final animation for EXAN-3007 (Winter 2024) - Abstraction in Motion course. The task was to create a piece of abstract visual animation for a music track by the New York-based band Vessels to Motherland, titled "Arrakis."

The rhythmic, repeating melody, reminiscent of a pulse, inspired me to create an animation incorporating waves, vibrations, and seismic bending. The project embraces abstraction primarily through its movement techniques, with all motion created using Geometry Nodes in Blender.

The animation was later featured in an immersive projection mapping show at Illuminarium Toronto in September 2024.
